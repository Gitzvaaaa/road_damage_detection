Training loss measures the objective on training examples, while validation loss measures predictive 
error on held-out examples without updating model parameters. The project records sample￾weighted mean cross-entropy for each epoch. Its validation pass uses evaluation mode, so dropout 
is disabled and BN uses running statistics [12].

monitoring whether validation loss improves sufficiently [1, Sec. 7.8].

example, after accepting loss 0.5000, a new value must be below 0.4999 to reset the counter. 
Smaller changes are compared against the unchanged reference in subsequent epochs [12].
Stopping and checkpoint selection are separate. The current configuration saves the highest 
validation-accuracy checkpoint, using lower validation loss to break ties. Improvements smaller than 
min_delta can still update that checkpoint. Evaluation explicitly loads the saved checkpoint; early 
stopping itself does not restore the in-memory model. The learning-rate scheduler also monitors 
validation loss, but uses its own patience setting [12].
2.5. Representative CNN Architectures
2.5.1. LeNet
LeNet-5 is an early CNN designed for handwritten character recognition. It processes a 32 × 32
grayscale input through convolution, subsampling, and classification stages. Its C1 layer produces 
six feature maps, S2 reduces their spatial resolution, C3 produces 16 feature maps, and S4 
performs further subsampling. C5 combines the remaining spatial features, followed by the F6 layer 
and the output stage [8].
The original architecture uses sigmoid-type nonlinearities and trainable subsampling, with a radial￾basis output layer. Modern teaching implementations often replace these details with ReLU, ordinary 
pooling, and a softmax classifier. LeNet illustrates the central CNN pattern of extracting local 
features, reducing spatial resolution, and combining the resulting representations for classification 
[8].
