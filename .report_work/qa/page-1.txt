2.2. Convolutional Neural Networks
2.2.1. Overview and Basic Architecture of CNNs
A convolutional neural network (CNN) processes grid-structured data such as images by learning 
local patterns and combining them across successive layers. Local connectivity restricts each filter 
to a small region, while parameter sharing applies the same filter at different spatial positions. These 
properties reduce the number of parameters relative to a fully connected transformation of the same 
image [1, Ch. 9].
A typical CNN classifier consists of convolutional layers, nonlinear activation functions, optional 
normalization and pooling layers, and a classification head. Earlier layers can represent edges and 
textures, while later layers combine them into features useful for classification. Convolution provides 
translation equivariance under appropriate stride and boundary conditions: shifting the input shifts its 
feature responses. It does not by itself guarantee that the final prediction is invariant to every 
translation [1, Ch. 9].
